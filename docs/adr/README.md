# ADRs do frontend

Esta pasta concentra _Architecture Decision Records_ curtos do projeto.

O objetivo não é substituir o README nem a documentação de arquitetura mais ampla. As ADRs servem para registrar decisões pontuais que afetam a estrutura do frontend e que poderiam gerar retrabalho se alguém mudasse sem contexto.

## Como ler

- cada ADR descreve uma decisão específica;
- a numeração é incremental para facilitar referência em PR, review e documentação;
- o foco está em contexto, decisão tomada, trade-offs e impacto esperado.
